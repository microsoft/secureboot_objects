# Contents of the DBX Folder

This folder contains the last auth2 DBX binaries that were signed using KEK 2011.

Because KEK 2011 has now expired, and newer DBX binaries are signed with KEK 2023, this
folder and its content should be considered obsolete and **will be deleted in 2027**.

If you were referencing content from this folder directly, you should move to using the new
`.auth2` binaries from either the `SignedByKEK2011` or `SignedByKEK2023` folders.
